# 棱野 RIDGELINE · 户外机能装备落地页

户外机能风运动装备品牌的产品展示页。品牌定位：高质量、高耐用度、高实用性。

## 页面结构

- **品牌头部导航**：滚动吸顶，移动端折叠为汉堡菜单。
- **Hero 卖点区**：SVG 山景绘制 + 产品插画，含品牌标语与「探索装备系列」入口。
- **设计理念区**：三条品牌主张（品质 / 耐用 / 功能）。
- **产品展示区**：4 款装备（外壳夹克、28L 徒步背包、机能长裤、五片折叠帽），每款含名称、简介、价格与原创 SVG 插画；支持按「机能穿着 / 背负系统 / 户外配件」筛选。
- **品牌故事区**：等高线视觉 + 品牌叙述。
- **预订入口**：预订意向表单，含规格联动、价格汇总、原生校验与结果反馈。
- **页脚**：品牌信息、导航与「信息使用说明」弹窗。

## 视觉方案

苔绿 / 岩灰为主色，信号黄绿作强调色；编号与参数使用等宽字体，整体呼应户外机能调性。产品插画为内联 SVG 手绘（每个实例使用唯一渐变 ID，避免重复 SVG 的 ID 冲突），不请求任何外部资源。

## 预订流程说明

表单行为由 `.env` 中的 `VITE_PREORDER_ENDPOINT` 决定：

- **留空（默认）**：进入「展示模式」，提交后仅生成本地清单预览，**不发送也不保存任何个人信息**。
- **配置为同源 HTTPS 接口**：提交后 POST 到该接口，需返回 `{"ok": true}` 才显示登记成功；请求带 15s 超时与基于 `requestId` 的防重入。

## 运行方式

需要 Node.js（建议 22 LTS）。

```bash
npm install
npm run dev -- --host 0.0.0.0
```

打开终端实际输出的 `Local` 地址（默认 `http://localhost:5173/`）。

> 注意：请勿直接双击 `index.html`。本项目使用以 `/` 开头的绝对资源路径与 Vite 专属语法（`import './style.css'`、`import.meta.env`），必须经开发服务器或构建产物访问。

生产构建：

```bash
npm run build      # 产物输出到 dist/，可部署到任意静态托管
npm run preview -- --host 0.0.0.0
```
